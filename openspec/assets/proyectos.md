Logtrics V2
Descripción corta (portafolio):

Logtrics es una plataforma SaaS B2B multi-tenant para forwarders y equipos de supply chain en LATAM. Digitaliza el ciclo logístico completo —desde la orden de compra y la solicitud de cotización (RFQ) a múltiples forwarders, hasta la comparación de ofertas, el tracking de contenedores en tiempo real y la gestión documental y financiera de cada embarque. Incluye análisis y validación asistida por IA de ofertas de flete, costeo por SKU, alertas operativas automáticas, integración de correo bidireccional con Gmail/Outlook y un ledger de créditos para operaciones facturables. Arquitectura segura por diseño: aislamiento estricto por tenant, control de permisos por rol en servidor y trazabilidad de eventos.

Versión de una línea (hero):

Plataforma logística inteligente que convierte el caos de cotizar, embarcar y controlar carga internacional en un flujo único, colaborativo y en tiempo real.

Bullets de impacto:

Centraliza RFQs, ofertas de forwarders y comparación de tarifas en un solo lugar
Tracking de contenedores en vivo (ShipsGo) con alertas operativas automáticas
Extracción y validación de órdenes de compra y ofertas de flete con IA
Costeo granular por SKU y reportería exportable multi-hoja
Bandeja de correo integrada: las respuestas de los forwarders se correlacionan solas
Multi-tenant real con seguridad y permisos aplicados en servidor
Stack tecnológico
Capa	Tecnologías
Frontend	Next.js 16 (App Router, Cache Components / PPR), React 19, TypeScript 5, Tailwind CSS 4, shadcn/ui (Base UI), Zustand
Backend	Next.js Server Actions & API Routes, Zod, arquitectura multi-tenant con RLS
Datos	Supabase — PostgreSQL, Auth, Storage, Realtime; migraciones SQL versionadas
IA	OpenAI (extracción de OC/PDF, análisis y validación de ofertas de flete)
Integraciones	Nylas & Microsoft Graph (email Gmail/Outlook), ShipsGo (tracking marítimo), DHL Express
Infra / Calidad	Vercel, Sentry, Vitest, pnpm, cron jobs (pg_cron)

links: https://www.logtrics.ai/ y repo privado cliente real.
